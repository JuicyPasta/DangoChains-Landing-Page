<h2>Cómo pasa cada sonido del español al japonés</h2>
<table class="st-table"><thead><tr><th>En español</th><th>En katakana</th><th>Ejemplo</th></tr></thead><tbody>
<tr><td>vocales a, e, i, o, u</td><td lang="ja">ア エ イ オ ウ</td><td>Ana → <span lang="ja">アナ</span></td></tr>
<tr><td>c (ca, co, cu), qu, k</td><td lang="ja">カ コ ク ケ キ</td><td>Carlos → <span lang="ja">カルロス</span>, Enrique → <span lang="ja">エンリケ</span></td></tr>
<tr><td>ce, ci, z, s</td><td lang="ja">セ シ サ ソ ス</td><td>Lucía → <span lang="ja">ルシア</span>, Gonzalo → <span lang="ja">ゴンサロ</span></td></tr>
<tr><td>j, ge, gi (y la x de Ximena)</td><td lang="ja">ハ ヒ フ ヘ ホ</td><td>José → <span lang="ja">ホセ</span>, Ángel → <span lang="ja">アンヘル</span></td></tr>
<tr><td>ga, go, gu, gue, gui</td><td lang="ja">ガ ゴ グ ゲ ギ</td><td>Miguel → <span lang="ja">ミゲル</span></td></tr>

<tr><td>ll</td><td lang="ja">ジャ ジ ジュ ジェ ジョ</td><td>Guillermo → <span lang="ja">ギジェルモ</span></td></tr>

<tr><td>f</td><td lang="ja">ファ フィ フ フェ フォ</td><td>Sofía → <span lang="ja">ソフィア</span></td></tr>

<tr><td>otra consonante sin vocal detrás</td><td>se le añade u (o tras t y d)</td><td>Carlos → <i>Ka-ru-ro-su</i>, Pedro → <i>Pe-do-ro</i></td></tr>
</tbody></table>
<p>Por eso los nombres en japonés suelen tener más sílabas: el japonés no tiene sílabas terminadas en consonante (salvo la <i>n</i>), así que cada consonante suelta se convierte en una sílaba propia.</p>

<h2>Preguntas frecuentes</h2>
<p><b>¿Y en kanji?</b> Los japoneses escriben los nombres extranjeros en katakana. Hay páginas que te «traducen» el nombre a kanji eligiendo caracteres por el sonido (<span lang="ja">当て字</span>, <i>ateji</i>), pero es un juego, no algo que se use de verdad. Si quieres un nombre japonés con significado, mira <a href="/es/nombres-japoneses-de-mujer/">nombres japoneses de mujer</a> y <a href="/es/nombres-japoneses-de-hombre/">de hombre</a>.</p>
<p><b>¿Por qué katakana y no hiragana?</b> El katakana es el sistema para palabras y nombres que vienen de fuera. En hiragana se leería igual, pero parecería un nombre japonés escrito por un niño.</p>
<p><b>¿Hay una sola forma correcta?</b> No hay una forma oficial. Algunas personas alargan la vocal acentuada (<span lang="ja">ルシーア</span>) o escriben la <i>ll</i> como <span lang="ja">リャ</span> o <span lang="ja">ヤ</span>; si en Japón ya escriben tu nombre de otra forma, usa esa. En pasaportes y tarjetas de residencia se usa el alfabeto latino.</p>
<p><b>¿Cómo me presento?</b> <span lang="ja">わたしは マリア です。</span> (<i>Watashi wa Maria desu</i>, «Soy María»). Sin <i>-san</i>: el sufijo nunca se usa con el propio nombre. Más frases en <a href="/es/hola-en-japones/">hola en japonés</a> y <a href="/es/frases-en-japones/">frases en japonés</a>.</p>

(function () {
  var inp = document.getElementById('nk-in'), out = document.getElementById('nk-out');
  if (!inp || !window.NombreKatakana) return;
  var kanaEl = document.getElementById('nk-kana'), romEl = document.getElementById('nk-romaji'), partsEl = document.getElementById('nk-parts');
  var sayB = document.getElementById('nk-say'), copyB = document.getElementById('nk-copy'), shareB = document.getElementById('nk-share'), msg = document.getElementById('nk-msg');
  var current = null, timer = null, tracked = false;
  function track(name, params) { try { if (typeof window.gtag === 'function') window.gtag('event', name, params || {}); } catch (e) {} }
  function esc(s) { return String(s).replace(/[&<>"]/g, function (c) { return { '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;' }[c]; }); }
  function render() {
    var r = window.NombreKatakana.toKatakana(inp.value);
    current = r.kana ? r : null;
    out.hidden = !current;
    msg.textContent = '';
    if (!current) return;
    kanaEl.textContent = r.kana;
    romEl.textContent = r.romaji.replace(/-/g, '');
    var html = [];
    r.words.forEach(function (w, i) {
      if (i) html.push('<span aria-hidden="true"><b lang="ja">・</b><small>&nbsp;</small></span>');
      w.parts.forEach(function (p) { html.push('<span><b lang="ja">' + esc(p[0]) + '</b><small>' + esc(p[1]) + '</small></span>'); });
    });
    partsEl.innerHTML = html.join('');
    clearTimeout(timer);
    timer = setTimeout(function () { if (!tracked) { tracked = true; track('name_katakana', { words: r.words.length, lang: 'es' }); } }, 1500);
  }
  inp.addEventListener('input', render);
  var synth = window.speechSynthesis, voice = null;
  function pickVoice() {
    if (!synth || typeof window.SpeechSynthesisUtterance !== 'function') return;
    var vs = synth.getVoices() || [];
    var ja = vs.filter(function (v) { return /^ja(-|_|$)/i.test(v.lang); });
    voice = ja.filter(function (v) { return v.localService; })[0] || ja[0] || null;
    sayB.hidden = !voice;
  }
  if (synth) { pickVoice(); if (synth.addEventListener) synth.addEventListener('voiceschanged', pickVoice); }
  sayB.addEventListener('click', function () {
    if (!current || !voice) return;
    synth.cancel();
    var u = new window.SpeechSynthesisUtterance(current.kana.replace(/・/g, '、'));
    u.voice = voice; u.lang = voice.lang || 'ja-JP'; u.rate = 0.9;
    synth.speak(u);
    track('name_katakana_say');
  });
  copyB.addEventListener('click', function () {
    if (!current) return;
    var text = current.kana;
    if (navigator.clipboard && navigator.clipboard.writeText) navigator.clipboard.writeText(text).then(function () { msg.textContent = 'Copiado'; }, function () { msg.textContent = text; });
    else msg.textContent = text;
    track('name_katakana_copy');
  });
  shareB.addEventListener('click', function () {
    if (!current) return;
    var url = location.origin + location.pathname + '#n=' + encodeURIComponent(inp.value.trim());
    var text = 'Mi nombre en japonés: ' + current.kana;
    track('name_katakana_share');
    if (navigator.share) { navigator.share({ title: 'Tu nombre en japonés', text: text, url: url }).catch(function () {}); return; }
    if (navigator.clipboard && navigator.clipboard.writeText) navigator.clipboard.writeText(text + ' ' + url).then(function () { msg.textContent = 'Enlace copiado'; }, function () { msg.textContent = url; });
    else msg.textContent = url;
  });
  function fromHash() {
    var m = /[#&]n=([^&]+)/.exec(location.hash);
    if (m) { try { inp.value = decodeURIComponent(m[1]).slice(0, 60); } catch (e) {} render(); }
  }
  fromHash();
  window.addEventListener('hashchange', fromHash);
})();
