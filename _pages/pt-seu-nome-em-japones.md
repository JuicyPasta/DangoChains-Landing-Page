<h1>Seu nome em japonês</h1>

<h2>Como cada som do português vira japonês</h2>
<table class="st-table"><thead><tr><th>Em português</th><th>Em katakana</th><th>Exemplo</th></tr></thead><tbody>
<tr><td>vogais a, e, i, o, u</td><td lang="ja">ア エ イ オ ウ</td><td>Ana → <span lang="ja">アナ</span></td></tr>
<tr><td>ão, ã, m e n no fim da sílaba</td><td lang="ja">アン / ン</td><td>João → <span lang="ja">ジョアン</span>, Joaquim → <span lang="ja">ジョアキン</span></td></tr>
<tr><td>j, ge, gi</td><td lang="ja">ジャ ジ ジュ ジェ ジョ</td><td>Júlia → <span lang="ja">ジュリア</span>, Gisele → <span lang="ja">ジゼレ</span></td></tr>

<tr><td>s entre vogais (som de z), z</td><td lang="ja">ザ ジ ズ ゼ ゾ</td><td>Isabela → <span lang="ja">イザベラ</span>, José → <span lang="ja">ジョゼ</span></td></tr>

<tr><td>ch, x</td><td lang="ja">シャ シ シュ シェ ショ</td><td>Xavier → <span lang="ja">シャビエル</span></td></tr>
<tr><td>l e r (o japonês não os distingue)</td><td lang="ja">ラ リ ル レ ロ</td><td>Lucas → <span lang="ja">ルカス</span>, Rafael → <span lang="ja">ラファエル</span></td></tr>
<tr><td>b e v</td><td lang="ja">バ ビ ブ ベ ボ</td><td>Vitória → <span lang="ja">ビトリア</span></td></tr>
<tr><td>h (mudo)</td><td>não se escreve</td><td>Helena → <span lang="ja">エレナ</span></td></tr>
<tr><td>outra consoante sem vogal depois</td><td>ganha um u (o depois de t e d)</td><td>Carlos → <i>Ka-ru-ro-su</i>, Pedro → <i>Pe-do-ro</i></td></tr>
</tbody></table>
<p>Por isso os nomes em japonês costumam ter mais sílabas: o japonês não tem sílabas terminadas em consoante (só o <i>n</i>), então cada consoante solta vira uma sílaba.</p>

<h2>Perguntas frequentes</h2>
<p><b>E em kanji?</b> Os japoneses escrevem nomes estrangeiros em katakana. Existem sites que «traduzem» o nome para kanji escolhendo caracteres pelo som (<span lang="ja">当て字</span>, <i>ateji</i>), mas é uma brincadeira, não algo que se use de verdade. Se você quer um nome japonês com significado, veja <a href="/pt/nomes-japoneses/">nomes japoneses</a>.</p>
<p><b>Existe uma única forma certa?</b> Não existe forma oficial. Muitos japoneses alongam a vogal tônica (Lucas → <span lang="ja">ルーカス</span>, Bruno → <span lang="ja">ブルーノ</span>) e escrevem o v com <span lang="ja">ヴ</span>; se no Japão já escrevem o seu nome de outro jeito, use esse. No passaporte e no cartão de residente vale o alfabeto latino.</p>
<p><b>Como me apresento?</b> <span lang="ja">わたしは マリア です。</span> (<i>Watashi wa Maria desu</i>, «Eu sou a Maria»). Sem <i>-san</i>: o sufixo nunca se usa com o próprio nome. Mais frases em <a href="/pt/ola-em-japones/">olá em japonês</a> e <a href="/pt/frases-em-japones/">frases em japonês</a>.</p>

(function () {
  var inp = document.getElementById('nk-in'), out = document.getElementById('nk-out');
  if (!inp || !window.NombreKatakana) return;
  var kanaEl = document.getElementById('nk-kana'), romEl = document.getElementById('nk-romaji'), partsEl = document.getElementById('nk-parts');
  var sayB = document.getElementById('nk-say'), copyB = document.getElementById('nk-copy'), shareB = document.getElementById('nk-share'), msg = document.getElementById('nk-msg');
  var current = null, timer = null, tracked = false;
  function track(name, params) { try { if (typeof window.gtag === 'function') window.gtag('event', name, params || {}); } catch (e) {} }
  function esc(s) { return String(s).replace(/[&<>"]/g, function (c) { return { '&': '&amp;', '<': '&lt;', '>': '&gt;', '"': '&quot;' }[c]; }); }
  function render() {
    var r = window.NombreKatakana.toKatakana(inp.value, 'pt');
    current = r.kana ? r : null;
    out.hidden = !current;
    msg.textContent = '';
    if (!current) return;
    kanaEl.textContent = r.kana;
    romEl.textContent = r.romaji.replace(/-/g, '');
    var html = [];
    r.words.forEach(function (w, i) {
      if (i) html.push('<span aria-hidden="true"><b lang="ja">・</b><small>&nbsp;</small></span>');
      w.parts.forEach(function (p) { html.push('<span><b lang="ja">' + esc(p[0]) + '</b><small>' + esc(p[1]) + '</small></span>'); });
    });
    partsEl.innerHTML = html.join('');
    clearTimeout(timer);
    timer = setTimeout(function () { if (!tracked) { tracked = true; track('name_katakana', { words: r.words.length, lang: 'pt' }); } }, 1500);
  }
  inp.addEventListener('input', render);
  var synth = window.speechSynthesis, voice = null;
  function pickVoice() {
    if (!synth || typeof window.SpeechSynthesisUtterance !== 'function') return;
    var vs = synth.getVoices() || [];
    var ja = vs.filter(function (v) { return /^ja(-|_|$)/i.test(v.lang); });
    voice = ja.filter(function (v) { return v.localService; })[0] || ja[0] || null;
    sayB.hidden = !voice;
  }
  if (synth) { pickVoice(); if (synth.addEventListener) synth.addEventListener('voiceschanged', pickVoice); }
  sayB.addEventListener('click', function () {
    if (!current || !voice) return;
    synth.cancel();
    var u = new window.SpeechSynthesisUtterance(current.kana.replace(/・/g, '、'));
    u.voice = voice; u.lang = voice.lang || 'ja-JP'; u.rate = 0.9;
    synth.speak(u);
    track('name_katakana_say');
  });
  copyB.addEventListener('click', function () {
    if (!current) return;
    var text = current.kana;
    if (navigator.clipboard && navigator.clipboard.writeText) navigator.clipboard.writeText(text).then(function () { msg.textContent = 'Copiado'; }, function () { msg.textContent = text; });
    else msg.textContent = text;
    track('name_katakana_copy');
  });
  shareB.addEventListener('click', function () {
    if (!current) return;
    var url = location.origin + location.pathname + '#n=' + encodeURIComponent(inp.value.trim());
    var text = 'Meu nome em japonês: ' + current.kana;
    track('name_katakana_share');
    if (navigator.share) { navigator.share({ title: 'Seu nome em japonês', text: text, url: url }).catch(function () {}); return; }
    if (navigator.clipboard && navigator.clipboard.writeText) navigator.clipboard.writeText(text + ' ' + url).then(function () { msg.textContent = 'Link copiado'; }, function () { msg.textContent = url; });
    else msg.textContent = url;
  });
  function fromHash() {
    var m = /[#&]n=([^&]+)/.exec(location.hash);
    if (m) { try { inp.value = decodeURIComponent(m[1]).slice(0, 60); } catch (e) {} render(); }
  }
  fromHash();
  window.addEventListener('hashchange', fromHash);
})();
